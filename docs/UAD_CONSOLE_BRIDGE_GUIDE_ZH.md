# UAD Console Bridge for EUCON

[English](UAD_CONSOLE_BRIDGE_GUIDE_EN.md)

当前应用版本：**v1.0.0**。

UAD Console 与 EUCON 之间的控制桥接程序。音频处理仍由 Apollo 与 UAD Console 完成。
本程序不替代 Console，不接管 EUCON 硬件发现、分配或翻页。

当前为待验收构建。软件与模拟测试不能替代 S3、Avid Control 和实际 Apollo 工作流程验收。
不要在重要录音中首次测试配置、路由、插件加载或敏感操作。

## 主界面

主界面仅显示状态，不提供音频操作：

- **连接状态**：在线声卡、采样率与时钟源。
- **控制室**：主监听音量、监听源、MUTE / DIM / MONO 和桥接控制上限。
- **逐通道状态**：通道名称与设备、单/双声道、电平、声像、信号与峰值、静音/独奏、UAD REC/MON 和输出位置。立体声保留左右两个声像读数。
- **分类标识**：保留话放、线路、S/PDIF、虚拟、ADAT、AUX、对讲的分类颜色与数量。
主监听不占普通推子通道。无数据时显示 `—`，不沿用断线前的读数。
通道列表支持滚动和键盘上下键、Page Up / Page Down，不受控制面的物理通道数限制。
点击列表只改变阅读位置，不会选择硬件通道或改变音频参数。
`M` / `S` 分别表示静音与独奏，激活时使用红色 / 黄色；信号与峰值使用声卡原始 dBFS。
`REC` 表示录入插件处理后的信号，`MON` 表示插件仅作用于监听；不支持的项目显示 `—`。

## 设置

### 通用

- **界面语言**：简体中文 / English。选择后可预览，保存后记住选择。
- **关闭窗口后继续运行**：默认开启。关闭窗口后驻留系统托盘；从托盘菜单显示窗口、打开设置或退出。
- **启动时隐藏主窗口**：启动后直接进入托盘，默认关闭。
- **登录 Windows 时启动**：仅对当前 Windows 用户生效，默认关闭。程序路径改变后应重新保存此选项。
- **日志文件夹**：按钮会先确保文件夹存在，再打开。

### 连接

- **自动连接 EUCON**：默认开启。声卡在线且没有其他冲突适配程序时发布应用模型，不会自动开放写入权限。
- **连接 EUCON**：手动连接或重试。
- **暂停控制**：撤销本次连接的写入权限，保留 EUCON 模型与显示，不重建节点。
- **CONFIG**：正式功能，默认启用。可在设置中关闭，改动在重启本程序后生效。

程序不会启动或重启 UAD Console、EuControl、驱动或声卡。Windows Fader Bridge for
EUCON 使用独立的应用与持久标识，可以与本程序同时运行。测试前只需退出重复的 UAD
桥接实例或 EUCON SDK 示例；本程序不会替你结束这些进程。

### 操作权限

| 方案 | 范围 |
| --- | --- |
| 只读 | 仅读取、显示和反馈，不写入音频参数 |
| 混音控制 | 通道控制与控制室；敏感操作、CONFIG 仍锁定 |
| 完整控制 | 开放目前已经实现并列入允许范围的全部控制；不会开放任意设备命令 |
| 自定义 | 分别配置下方四项 |

四项权限分别为：

1. **通道控制**：当前在线且支持的通道，含推子、声像、静音、独奏、发送、路由、前级和已加载插件。
2. **控制室**：独立的主监听音量、MUTE、DIM、MONO、监听源和 TALK。
3. **敏感操作**：48V、UNISON 参数和对讲送监听。需要通道控制权限；请先确认麦克风兼容性与监听环境。
4. **声卡与插件配置**：已实现的 CONFIG 设置、插件选择、已有预置调用。旋转只预选，按 In 确认。CONFIG 扩展未启用时，需要先重启启用。

点击“应用权限”并确认后才生效。授权本身不改变音频参数。该授权在本次程序运行期间持续有效，直到用户主动切换只读或断开桥接；短暂断线、状态刷新和单次操作失败不会把权限改回只读，连接恢复后会按最新状态自动继续。
输入源、输出路由、单双声道和插件拓扑改变时，旧页面上的操作会立即作废；程序以最新模型重新绑定，不重放旧命令。启动时恢复权限仍只对已确认的声卡系统生效。
“完整控制”允许全部已实现且列入范围的操作。普通混音参数在最新设备身份、控件类型和范围校验后实时发送；EUCON 控制事件会立即唤醒处理线程，不依赖界面刷新定时器。连续手势最多以 100 Hz 发送，并只保留尚未发送的最新位置，不重放中间积压值。Console 的实时状态回传负责最终校正。插件装卸、预置和 CONFIG 设置仍在写入前后执行完整确认；失败只取消该次操作，不撤销用户权限，也不会自动重试已经发送的命令。

### 安全限制

**主监听音量上限**可设为 −96 至 **0 dB**，默认 −20 dB。它只限制经本桥接发出的音量控制：

- 保存上限不会改变当前音量。
- 当前音量高于所选上限时仍可控制；MUTE、DIM、MONO、监听源和 TALK 不受阻断。下一次由桥接器发出的音量目标会被限制在上限以内。
- Console 和硬件上的操作不受此软件上限约束。
- 取消静音、退出 DIM、切换监听源或修改模拟输出参考电平仍可能变响。这不是声压限制器。

**启动时恢复已保存权限**默认关闭。开启后，程序启动并连接到已确认的同一声卡系统时恢复。
勾选此选项后，至少对已连接设备应用一次权限，才能记录确认的设备身份。

**立即切换为只读**会阻止后续未发送的控制，但不会改变声卡当前状态。要让后续启动继续保持只读，保存修改后的设置。
已经送出的指令不能撤回；连接丢失后也无法保证已开启的 TALK 自动关闭，必要时使用 Console 或硬件处理。

## 安装依赖与文件位置

需要 Windows 11 x64、Apollo / UAD Console 的正常运行环境，以及匹配的 Avid EUCON 运行环境。
从源代码构建还需要 Visual Studio C++ v143、Windows SDK 和单独取得的 Avid EUCON SDK。
仓库不包含厂商 SDK、手册、示例、安装包或库文件。

本轮隔离构建：`artifacts/uad-console-bridge-channels/Release/ApolloBridge.Eucon.exe`。
可执行文件暂保留内部工程名称，窗口、图标、文件属性与 EUCON 显示名称使用新产品名。
EUCON 持久标识保持不变，以保留既有布局。

设置：`%LOCALAPPDATA%\UAD Console Bridge\EUCON\settings.json`。
日志：同目录下的 `logs`。旧 Apollo Bridge 文件夹中的历史日志保留，不自动删除。
日志分享前请自行检查内容。

## 开发与验收

```powershell
# 构建并运行纯逻辑和模拟通信测试，不启动程序
.\scripts\build-apollo.ps1 -TransportTests -NativeOutputName uad-console-bridge-channels

# 界面预览：不连接设备、不初始化 EUCON、不保存设置
& .\artifacts\uad-console-bridge-channels\Release\ApolloBridge.Eucon.exe --ui-preview --preview-connected

# 设置文件与启动命令格式的隔离测试，不修改真实启动项
& .\artifacts\uad-console-bridge-channels\Release\ApolloBridge.Eucon.exe --desktop-self-test | Out-String

# 旧调试面板，仅供开发自用
& .\artifacts\uad-console-bridge-channels\Release\ApolloBridge.Eucon.exe --diagnostics --experimental-config
```

首次实机验收：先只读核对 S3 与 Avid Control 的名称、通道、翻页、控制室和反馈；
再在低监听音量、安全测试通道上逐项开放权限。确认完整控制、上限、暂停、托盘恢复与退出的行为。
真实的 48V、TALK、插件加载和路由修改仅由操作者在确认安全后测试。

详细控制映射见 [底层功能与旧调试界面说明](APOLLO_GUIDE_ZH.md)，
CONFIG 范围见 [实验记录](APOLLO_CONFIG_EXPERIMENT.md)。
